
# DCOIN Network

Independent blockchain network with its own wallet, test token, validator and block explorer.

## Network Information

- Name: DCOIN
- Symbol: DCO
- Total Supply: 7,000,000 DCO
- Decimal: 8
- Network: DCOIN Testnet
- Consensus: Validator-based
- Mining: Disabled

## Components

- DCOIN Blockchain Node
- DCOIN Validator
- DCOIN RPC API
- DCOIN Web Wallet
- DCOIN Test Token (TDCO)
- DCOIN Block Explorer

## Development

DCOIN Network is currently under development.
